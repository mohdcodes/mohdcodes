### 🚀 Featured projects

| Project | What it is | Stack |
|---|---|---|
| [**AgentArgus**](https://github.com/mohdcodes/AgentArgus) | Evaluation, observability and reliability for LLM agents, framework-agnostic. RAG and agent-behaviour metrics, OpenTelemetry traces, retries, fallbacks and circuit breakers. Published on PyPI. | Python · OpenTelemetry |
| [**CallFlow-AI**](https://github.com/mohdcodes/CallFlow-AI) | A 24×7 AI calling desk: dials contacts, holds real conversations, extracts typed results and escalates only what needs a person. Built for the CALL-E hackathon. | FastAPI · Next.js |
| [**RAAAAG**](https://github.com/mohdcodes/RAAAAG) | Voice-enabled, cross-lingual RAG over 14 Indic languages, with cited answers and per-stage latency. Built for Hacker House Goa. | FAISS · ONNX · FastAPI · Next.js |
| [**pyoverload**](https://github.com/mohdcodes/pyoverload) | Function and method overloading for Python based on type signatures. Published on PyPI as `methodoverload`. | Python |
| [**LaTeX OCR**](https://github.com/mohdcodes/LaTex-OCR-with-llama-vision-model) | Turns photos of equations into LaTeX with Llama 3.2 Vision, fully offline. | Ollama · Streamlit |
| [**Kokoro**](https://github.com/mohdcodes/kokoro) | Cafe ordering web app and PWA with live order tracking and a role-based admin dashboard. | Next.js · Supabase |
